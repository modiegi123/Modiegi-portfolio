# Modiegi Portfolio

Personal portfolio website for Modiegi, a Junior Full Stack Developer with 2 years of experience.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Sections

- Hero / Introduction
- About Me
- Skills
- Projects (placeholders — to be updated with real projects)
- Experience
- Contact

## Running locally

Just open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Deploying with GitHub Pages

1. Push this repo to GitHub (already done if you're reading this on GitHub).
2. Go to **Settings > Pages**.
3. Set the source to the `main` branch, root folder.
4. Your site will be live at `https://modiegi123.github.io/Modiegi-portfolio/`.
